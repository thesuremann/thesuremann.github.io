# Sudoku HTML v1.8.0

v1.8.0 completes the repository-wide migration of first-party executable source from JavaScript to TypeScript while preserving Sudoku behavior and all existing distribution modes.

## Highlights

- Migrated browser application, extension background, build/server tooling, unit tests, Playwright tests, and configuration to TypeScript.
- Kept distributed artifacts browser-native: the standalone `Sudoku.html` and extension still contain JavaScript/HTML/CSS only and require no TypeScript runtime.
- Preserved deterministic puzzle generation exactly against 20 frozen v1.7.1 seed/clue fixtures.
- Preserved v1.7.1 save-file compatibility, storage keys, preference semantics, extension permissions, and Manifest V3 architecture.
- Added stricter runtime boundaries for DOM elements, save parsing, browser preferences, and state transitions.
- Added focused pure board-analysis/state helpers after parity, with differential tests against the pre-refactor implementation.
- Hardened the retained single-file assembler so unsupported imports, circular dependencies, and invalid generated classic scripts fail during build instead of at browser runtime.
- Expanded automated coverage to 29 unit tests and 10 Playwright tests, including direct `file://` execution and unpacked-extension service-worker/UI smoke.
- Adopted TypeScript 7.0.2 as the release compiler and pinned Playwright 1.59.1 exactly for reproducible browser-tooling behavior.

## Compatibility

There are no intentional gameplay or UI behavior changes in this release. Save-file format version remains `1`, and v1.7.1 save files remain supported.

`noUncheckedIndexedAccess` is enabled repository-wide. Its earlier TypeScript 7.0.2 trial produced 91 diagnostics; before human UAT those accesses were converted to checked indexed-access boundaries and targeted guards without adding non-null-assertion or ignore escapes. Exact TS7 acceptance then passed with 29/29 unit tests and 10/10 Playwright tests, followed by 14/14 human UAT PASS.
